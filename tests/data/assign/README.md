# Correlation data: assign

`assign` aliases at the top of a flat netlist, each form the reference's `VerilogReader::mergeAssignNet`
merges (OpenSTA cc9027d6):
- an output port named by the net that drives it (`assign y = q1`);
- a wire that is another name for an input port (`assign n4 = b`);
- two output ports on one net (`assign z = n3, w = n3`);
- loads on both names of one internal net, before and after the assign (`assign n5 = n6`);
- a port fed straight through (`assign f = a`);
- a port tied low (`assign k = 1'b0`).

The library is `../correlation`'s. The `.golden` / `.hold.golden` files are the reference's
(`reference.txt`), regenerated by running it on these files, never edited. The order of each merged
net's terms and pins is pinned in `load`'s unit test, from the reference's own `term_iterator` /
`pin_iterator` on this netlist.
