# Correlation data: crpr

CRPR's common pin (`CheckCrpr::findCrpr`, OpenSTA 9ef4b4f0 in the pin's cc9027d6): the capture
clock path backed up to the first pin the launch clock path has, credited whatever the two
paths' transitions there (`sta_crpr_mode same_pin`, the default). r1 -> r3 meet at b0/X rising
on both sides, r1 -> r2 rising and falling: the reference credits both (0.018976). Propagated clocks
and early/late derates make the credit non-zero. The library is `../correlation`'s. The
`.golden` / `.hold.golden` files are the reference's (`reference.txt`), regenerated by running it
on these files, never edited.
