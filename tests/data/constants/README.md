# Correlation data: constants

The netlist of `../correlation` with pins tied to `1'b0` / `1'b1` and moved onto a
`supply0` and a `supply1` net (`rv_plic_lite_tied.v`, written by a deterministic script from
that netlist alone), timed under `base`, `tight` and `case` (case analysis and logic values).
The library is `../correlation`'s. The `.golden` / `.hold.golden` files are the reference's
(`reference.txt`), regenerated by running it on these files, never edited.
