# Correlation data: spef

The netlist of `../correlation` with every net's RC network from `rv_plic_lite.spef`, a synthetic
detailed SPEF written by a deterministic script from the netlist alone (RC trees, coupling
capacitors, corner triplets, loop and self resistors, a name map), timed under `base` and `tight`.
The library is `../correlation`'s. The `.golden` / `.hold.golden` files are the reference's
(`reference.txt`), regenerated by running it on these files, never edited.
